# Alanpire design

Draft 0.1. Read `../../AUDIT.md` and `../../REFERENCES.md` first.

## Purpose

Help a UAE industrial buyer assess technical relevance, accountable expertise and the next step without confusing prior personnel experience with UAE entity contracts.

## Rules

- Separate exact licensed activities from commercial service groupings.
- Keep prior-work attribution visible on cards and case studies.
- Never replace a Russian reference with Dubai stock photography.
- When no approved photograph exists, use original technical illustration with an explicit “illustrative” caption.
- Use one primary enquiry action and a quieter case-study action.
- Test EN, AR RTL and RU at mobile and desktop widths.
- Treat automated accessibility results as findings, not certification.

## Example

Before: a blank card says “Asset required: Route alignment drawing”.

After: an original water-corridor illustration with a visible caption stating it is not an as-built drawing; retain the verified project scope beside it.

## Checklist

- [ ] Images have an ownership/provenance record.
- [ ] Country and entity attribution are explicit.
- [ ] No truncated Russian or Arabic headings.
- [ ] Focus, contrast, target sizing and reduced motion checked.
- [ ] Enquiry destination is configured before launch.
